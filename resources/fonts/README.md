# Fuentes

`DejaVuSans.ttf` y `DejaVuSans-Bold.ttf` (DejaVu Fonts, licencia libre derivada de Bitstream Vera;
https://dejavu-fonts.github.io/License.html), copiadas de `dompdf/dompdf/lib/fonts`.

Las usa `App\Services\Planeacion\ImagenResumenPrograma` para dibujar con GD la hoja resumen del
Programa semanal que va en el correo. Tienen los acentos, la «ñ» y el signo menos (−).
